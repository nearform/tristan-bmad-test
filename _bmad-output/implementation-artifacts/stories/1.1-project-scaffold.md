# Story 1.1: Project scaffold and database

Status: ready-for-dev

## Story

As a developer,
I want a pnpm monorepo with API package and Prisma connected to PostgreSQL,
so that todos can be persisted with migrations.

## Acceptance criteria

1. **Given** a fresh clone, **when** I install deps and run migrations against Postgres, **then** the `Todo` table exists per schema.
2. **Given** `DATABASE_URL`, **when** the API starts, **then** Prisma client connects without error.

## Tasks / Subtasks

- [ ] Root `package.json`, `pnpm-workspace.yaml`, `apps/api` with TypeScript
- [ ] Prisma schema + initial migration
- [ ] Seed optional (not required)

## Dev notes

- Schema: `Todo` id UUID, description String, completed Boolean default false, createdAt, updatedAt.

## Testing

- **Integration:** DB connectivity in `ready` test (story 1.3)
