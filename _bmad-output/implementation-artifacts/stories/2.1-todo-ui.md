# Story 2.1: Todo UI and API integration

Status: ready-for-dev

## Story

As a user,
I want to manage todos in the browser with clear loading and error states,
so that I can trust the app for daily capture.

## Acceptance criteria

1. List loads on mount; **loading** then **data** or **error**.
2. Add todo validates non-empty description client-side.
3. Toggle complete and delete update the server and UI.
4. **Empty** state when no todos.
5. Completed todos visually distinct (strikethrough + checkbox).

## Testing

- **Component tests:** `TodoList` empty/loading/error; row toggle/delete callbacks.
- **E2E:** covered in story 2.2.
