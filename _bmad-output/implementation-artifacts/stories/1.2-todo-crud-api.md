# Story 1.2: Todo CRUD API

Status: ready-for-dev

## Story

As a user (via client),
I want create, list, update, and delete todos through a REST API,
so that my tasks are stored reliably.

## Acceptance criteria

1. **POST /todos** creates a todo; **400** on empty/oversized description.
2. **GET /todos** returns all todos sorted newest first.
3. **PATCH /todos/:id** updates `completed` and/or `description`; **404** if missing.
4. **DELETE /todos/:id** returns **204**; **404** if missing.

## Testing

- **Integration (required):** one `describe` per route with happy + error paths using Fastify `inject()` and test database.
