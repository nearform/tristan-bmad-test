## Story

As QA,
I want Playwright tests for core journeys,
so that regressions are caught automatically.

## Acceptance criteria

1. Minimum **5** tests: create todo, mark complete, delete todo, empty state visible, error handling (simulated API failure or network).
2. Tests pass against local `web` + `api` URLs from env.

## Testing

- **E2E:** Playwright + optional `@axe-core/playwright` for a11y smoke.
