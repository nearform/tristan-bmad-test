# Story 3.1: Docker delivery

Status: ready-for-dev

## Story

As an operator,
I want Dockerfiles and Compose profiles,
so that the full stack runs with one command.

## Acceptance criteria

1. Multi-stage Dockerfiles for `web` and `api` with non-root users and HEALTHCHECK.
2. `docker compose --profile prod up` starts db, api, web; web can reach API.
3. API runs migrations before serving.
