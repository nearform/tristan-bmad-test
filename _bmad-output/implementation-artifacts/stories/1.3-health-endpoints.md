# Story 1.3: Health and readiness endpoints

Status: ready-for-dev

## Story

As an operator,
I want `/health` and `/ready` endpoints,
so that orchestration can route traffic only when the service and DB are usable.

## Acceptance criteria

1. **GET /health** always returns 200 when process is up (no DB).
2. **GET /ready** returns 200 when DB query succeeds; **503** when DB fails.

## Testing

- **Integration:** mock or real DB for ready success; failure case optional with invalid URL in isolated test.
